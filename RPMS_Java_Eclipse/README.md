# Recruitment & Placement Management System - Java Starter Project

This ZIP contains a student-friendly Java + JDBC + MySQL starter implementation.

## Included

- Model classes
- DAO interfaces
- JDBC DAO implementations
- Service layer
- Eligibility logic
- Custom exceptions
- DB connection utility
- Validation utility
- File-based activity log
- Console application
- MySQL DDL + sample data scripts

## Setup

1. Install MySQL.
2. Run `sql/rpms_full_setup.sql`.
3. Add MySQL Connector/J JAR to the Java project's classpath.
4. Open `DBConnection.java`.
5. Change database username/password if required.
6. Run `RecruitmentApp.java`.

## Important

The HTML/CSS prototype is a separate deliverable and is not connected to this Java project.

This is a starter project. Students are expected to extend Company, Interview, Offer,
Placement, reports, status workflow and testing as per the specification.
